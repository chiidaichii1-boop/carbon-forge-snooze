A one-line roast of an alarm clock that rings at 6 AM on a Saturday.

`main.py` (Python 3 stdlib only, no network, deterministic) writes the roast
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`).

Run it:

```sh
python3 main.py
```
